# Referencias visuales aportadas por el usuario

Recibidas el 2026-10-13. Copias intactas de los 18 PNG adjuntos, verificadas contra los originales por SHA-256. Se conservan para definir interacción y disposición del software. No son resultados del proyecto ni evidencia de prestaciones del iPhone.

Los PNG se conservan solo en la carpeta local y están excluidos de Git mediante `.gitignore`. Los enlaces a esas imágenes requieren las copias locales; no estarán disponibles al clonar el repositorio.

La especificación funcional está en [viabilidad y flujo](../FEASIBILITY_AND_WORKFLOW.md) y el orden de implementación en [ROADMAP.md](../../ROADMAP.md).
